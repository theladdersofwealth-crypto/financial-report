# Global Market Desk

한국 투자자가 글로벌 시장 흐름과 국내 증시 영향을 함께 읽는 초대 회원 전용 웹앱입니다. Cloudflare Workers에서 화면·API를 실행하고, SQLite 기반 Durable Object에 계정·접속·채팅 기록을 보관합니다. GitHub 저장소와 Cloudflare Workers Builds를 연결하면 이후 push로 배포합니다.

## 포함 기능

- 시장 요약, 주요 지표, 자산별 현황, 섹터·종목, 기간별 전망, 데이터 출처
- 실제 데이터와 명시적으로 분리된 화면 체험 모드
- 최초 관리자 등록, 관리자 발급 회원 계정, 임시 비밀번호 변경, 계정 정지
- HttpOnly 세션과 서버 권한 검사, 접속·활동시간 추정 기록
- 고유 계정 기준 실시간 접속자, 설정 인원 이상에서 채팅, 메시지 기록
- 연결되지 않은 지표는 빈값과 상태 표시. 뉴스·전망·가격을 만들어 실데이터로 표시하지 않음

## 로컬 실행

Node.js 22 이상을 사용합니다.

```bash
npm ci
npm run dev
```

`.dev.vars`에 로컬 전용 `BOOTSTRAP_TOKEN`을 지정할 수 있습니다. 비밀값을 저장소에 커밋하지 마세요. 최초 관리자 설정 후에는 일반 로그인으로 접속합니다. 테스트는 격리된 임시 데이터베이스를 사용합니다.

```bash
npm run check
npm test
npm run build
```

## Cloudflare에 별도 사이트로 배포

1. 소스 저장소는 [`theladdersofwealth-crypto/financial-report`](https://github.com/theladdersofwealth-crypto/financial-report)의 `main` 브랜치입니다. 저장소 공개 여부와 별개로 실제 회원·시장 API는 서버 로그인이 필요합니다.
2. Cloudflare 대시보드의 **Workers & Pages → Create application → Import a repository**에서 `financial-report` 저장소를 선택합니다.
3. 프로젝트 이름은 `financial-report`, 루트 디렉터리는 저장소 루트(`/`)로 지정합니다.
4. 의존성 설치는 `npm ci`, 빌드 명령은 `npm run check`, 배포 명령은 `npm run deploy`를 사용합니다. 정적 자산은 `public/`, Worker는 `src/worker.js`이며 설정은 `wrangler.toml`에 있습니다. 별도 프런트엔드 빌드는 필요하지 않습니다. **Pages가 아니라 Worker 프로젝트로 연결합니다.**
5. SQLite Durable Object `DESK`는 `v1` migration으로 생성됩니다. 별도의 D1 데이터베이스를 만들거나 ID를 입력할 필요가 없습니다. 계정에서 Durable Objects 이용을 활성화해야 할 수 있습니다.
6. 배포 주소에서 **최초 관리자 설정**을 선택하고 별도로 받은 설정 코드와 원하는 관리자 아이디·이름·비밀번호를 입력합니다. 설정 코드는 저장소에 없고 SHA-256 해시만 설정에 포함되어 있습니다. 관리자가 한 번 등록되면 재등록할 수 없습니다.
7. 관리 화면에서 지인 계정을 발급합니다. 첫 로그인 시 회원이 임시 비밀번호를 변경합니다.

최초 연결 이후에는 해당 브랜치 push가 배포를 시작합니다. 다른 기존 사이트의 자동 배포 설정은 이 새 사이트에 자동으로 적용되지 않습니다. 기존 앱을 덮어쓰지 않도록 새 프로젝트를 사용합니다.

## 데이터와 분석

가격마다 공급원·관측 시각·지연 또는 일별 여부를 확인합니다. 일별 통계는 실시간 시세가 아닙니다. 미국장 종가·한국장 시세·코인의 24시간 등락은 서로 다른 기준입니다. 공급원 실패 시 마지막 값을 현재 값으로 가장하지 않습니다.

기본 연결 및 추가 키의 정확한 지원 범위는 `src/market.js`와 화면의 데이터 출처에서 확인할 수 있습니다. 추가 키는 Cloudflare **Settings → Variables and Secrets**에 저장합니다. `.env.example`에는 키 이름만 있습니다.

키가 없을 때의 전망은 수집된 데이터의 범위와 부족한 근거를 함께 표시하는 지표 기반 조건부 해석입니다. 체험 모드 전망은 가상 예시입니다. `OPENAI_API_KEY`를 Secrets에 등록하면 수집된 관측 자료만을 바탕으로 생성형 AI 분석을 추가하며, 시세 변화와 별개로 같은 모델의 기존 분석을 30분 동안 캐시로 재사용합니다. 최신 시세와 분석 기준 시각을 구분해서 표시합니다. 캐시는 Cloudflare 지역별이므로 전 세계에서 정확히 한 번만 호출됨을 보장하지는 않습니다. `OPENAI_MODEL`로 운영 모델을 지정할 수 있습니다(기본 `gpt-6-luna`). 응답 검증 실패·시간 초과 시 기존 지표 해석을 유지합니다. 실제 API 호출은 키 등록 전에는 실행하지 않으며, 사용료는 API 제공업체 기준으로 발생합니다. 모델 지원 여부와 계정 권한을 운영 연결 시 확인하세요.

지인에게 제공하는 경우에도 각 원자료의 이용·공유 조건을 확인해야 합니다.

## 접속·활동 집계

여러 탭이나 기기로 접속해도 현재 접속자는 고유 계정 기준으로 계산합니다. 접속시간과 활동시간은 연결·화면 표시·최근 활동 신호를 바탕으로 한 추정치이며 실제 독서시간이 아닙니다. 수집 안내는 로그인 화면에서 제공하며, 상세 기록은 관리자만 볼 수 있습니다.

원문 비밀번호·세션 토큰은 데이터베이스에 저장하지 않습니다. 비밀번호는 salt를 포함한 PBKDF2, 세션은 난수 토큰의 해시로 저장합니다. 회원 정지·비밀번호 초기화 시 세션을 폐기합니다. 채팅과 로그 보관기간 및 서버 접근 제어는 `src/room.js`에서 확인할 수 있습니다.

## 구성

```text
public/          한국어 대시보드·로그인·관리자·체험 화면
src/worker.js    Cloudflare 진입점, 정적 파일·API 라우팅
src/room.js      계정·세션·기록·실시간 접속자·채팅
src/market.js    외부 데이터 수집과 출처·시점 처리
tests/          격리된 Worker 런타임 통합 검증
wrangler.toml   자산·Durable Object·정기 갱신 설정
```
